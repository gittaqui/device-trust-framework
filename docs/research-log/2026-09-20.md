## Results

Frozen synthetic design: 50,000 sessions per dependence condition, seed `20260920`, original scenario prevalence/marginal ranges/labels, additive model, existing hard gates. Positive dependence was induced with the repository's one-factor Gaussian-copula generator.

At ALLOW threshold 0.80, unsafe risk among ALLOW decisions increased from 0.239% (rho=0) to 5.376% (rho=0.8). At threshold 0.85, the independent condition observed zero unsafe ALLOWs (95% Wilson upper bound about 0.015%), but rho=0.8 produced 0.195% unsafe risk (95% CI 0.148–0.258%). This falsifies the tempting synthetic interpretation that 0.85 is intrinsically failure-free.

## Limitations

All results are synthetic. The copula structure, scenario ranges, prevalence and labels are authored assumptions. Wilson intervals quantify Monte Carlo sampling uncertainty conditional on those assumptions, not uncertainty about real enterprise populations. The experiment does not model temporal dependence, tail-specific dependence, measurement error, concept shift, or unseen attacks. No confidential employer data was used.

The connected GitHub environment can write source but does not execute pytest; targeted tests were added but no test-suite pass is claimed here. Numerical results were independently recomputed from the committed algorithm before recording them.

## Next step

External telemetry validation remains the highest-value blocker. If external data remains unavailable, add a harder synthetic overlap experiment in which safe and unsafe scenario marginals deliberately overlap while dependence varies, then report per-scenario errors. This would challenge both separability and independence assumptions simultaneously.
