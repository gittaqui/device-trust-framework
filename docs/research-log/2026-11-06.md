# Research log — 2026-11-06: executable device-cluster bootstrap contract

## Starting state
Read the existing 2026-11-05 research log, 2026-11-02 temporal outage protocol, and 2026-11-04 Markov run-length estimator in the repository. The prior log prespecified paired device-cluster bootstrap inference but no implementation.

## Completed
Implemented a standalone standard-library Python prototype, `longitudinal_cluster_bootstrap.py`, and seven unit tests in a local reproducibility package. The implementation consumes one record per device with device ID, fixed unsafe label, interval count, and ordinary-ALLOW counts in paired arms. It computes an interval-weighted paired unsafe-ALLOW difference and 95% percentile interval using whole-device resampling (2,000 replicates by default, seed 20261105). It preserves pairing, checks duplicate IDs, bounds, invalid records, absent eligible class, and insufficient independent unsafe devices. Undefined replicates are counted, not replaced by zero.

## Results and limitations
Only **software verification** results, not new empirical trust-model performance findings. The synthetic test fixtures are deliberately tiny and artificial. The percentile bootstrap does not address shared infrastructure outage episodes, generator misspecification, or model validity. The implementation requires per-device aggregated counts and therefore does not yet calculate decision flips or safe DENY/STEP_UP. Device independence is assumed; for common-cause outages the resampling unit must be independent episodes. No confidential employer data was accessed.
