## Research advance
Implemented a separate synthetic Gaussian AR(1) stationary-bootstrap coverage audit locally, with circular geometrically distributed blocks, basic bootstrap 95% intervals, paired synthetic datasets across block choices, and six passing unit tests. Local experiment uses 300 independent datasets per condition and 399 resamples per dataset; episode counts 30 and 100; phi 0, 0.6, 0.9; mean block lengths 3 and 8; seed 20261119. Results are statistical coverage, NOT endpoint security effectiveness.

Maximum Monte Carlo standard error is 2.89 percentage points. The basic stationary bootstrap improves over naive IID inference in strongly correlated cases but remains severely undercalibrated; larger blocks can worsen coverage when phi=0. This does not validate the bootstrap for the device-trust engine.
