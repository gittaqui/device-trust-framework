Both references were added to the literature matrix and bibliography. They are used to frame `STEP_UP` as an abstention/reject action, not to claim that device-trust scoring itself originates from those papers.

The experiment keeps feature vectors and policy decisions fixed while progressively relabeling a nested subset of the synthetic `identity_risk` scenario as legitimate. Fractions are 0%, 10%, 25%, 50%, and 100%, using `overlap_seed=20260909`. This is intentionally a label-sensitivity stress test rather than a prevalence model.

## Main results

The 50,000-row seeded population contains 3,912 `identity_risk` rows.

- Original labels: guarded 0.75 safe STEP_UP = 5.40%; false ALLOW = 1.24%.
- 25% target overlap (995 rows actually relabeled): guarded safe STEP_UP = 8.54%; false ALLOW = 1.30%.
- 50% target overlap (1,965 rows): guarded safe STEP_UP = 11.40%; false ALLOW = 1.37%.
- 100% overlap: guarded safe STEP_UP = 16.63%; false ALLOW = 1.52%.
- The additive 0.80 policy is even more sensitive to benign overlap, reaching 23.62% safe STEP_UP at full overlap.

The key conclusion is negative but useful: the earlier claim that the guard has little benign-friction cost is not robust to label overlap. Guard thresholds require calibration against externally observed benign identity/anomaly behavior.

## Limitations

- Results remain synthetic and are not evidence of production security effectiveness.
- Relabel fractions are hypothetical stress parameters, not empirical prevalence estimates.
- Relabeling changes ground-truth interpretation but not feature values.
- No cost model yet exists for STEP_UP resolution (MFA, remediation, analyst review, or user abandonment).
- External telemetry is still required before choosing or recommending guard thresholds.

## Next step

Use temporally separated external enterprise telemetry to estimate how often legitimate activity occupies low-identity/high-anomaly regions, then report error-versus-abstention curves rather than a single preferred threshold. If labeled external access outcomes remain unavailable, the next methodological step should define an explicit cost-sensitive abstention analysis over a range of STEP_UP costs rather than selecting a policy by accuracy alone.
