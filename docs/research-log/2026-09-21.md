## Results

At fixed ALLOW threshold 0.80 and 50,000 synthetic sessions per condition, positive dependence (`rho=0.6`) plus progressive pooled-range overlap caused conditional unsafe-ALLOW risk to rise from 4.031% at overlap 0 to 29.862% at overlap 0.75. Safe-session ALLOW recall simultaneously fell from 89.667% to 17.934%. At the strongest tested stress, all six unsafe scenarios produced some ALLOW decisions.

## Interpretation

The framework's favorable synthetic operating point depends materially on class separability as well as dependence structure. The experiment is intentionally adversarial and falsifies any claim that a fixed score threshold is intrinsically safe. It supports a narrower manuscript claim: multidimensional policies should be evaluated under explicit structural stress, with abstention and calibration monitoring, rather than validated only on a separable synthetic generator.

## Limitations

All results are synthetic. Pooled-range interpolation is not empirically calibrated and is designed to erode separability. The Gaussian one-factor copula is a simple dependence model. Labels, scenario prevalence, and signals remain authored. No employer or confidential telemetry was used. The connected GitHub environment permits source changes but does not provide a Python execution action; numerical results were independently reproduced in a local analysis runtime, while the committed pytest tests were not executed through GitHub. No claim of repository-wide test success is made.

## Next step

External validation remains the priority. If suitable public endpoint telemetry cannot be mapped to the eight signals, the next controlled study should compare the additive model against a learned but interpretable baseline (for example logistic regression) using train/calibration/test separation under the same overlap/dependence protocol, with bootstrap or repeated-seed uncertainty. This would test whether observed failures are specific to hand-authored weights or inherent to the stressed evidence.
