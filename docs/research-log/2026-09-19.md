## Fresh literature verification

Verified Robert G. Newcombe, “Two-sided confidence intervals for the single proportion: comparison of seven methods,” *Statistics in Medicine*, 17(8), 857–872 (1998), DOI `10.1002/(SICI)1097-0258(19980430)17:8<857::AID-SIM777>3.0.CO;2-E`. The study evaluates seven methods over 96,000 parameter-space points and recommends score/tail-area approaches over simpler intervals with poor coverage behavior.

## Results

Population: 50,000 synthetic sessions; generator seed `20260903`.

Key operating points:
- threshold 0.75: unsafe ALLOW risk 8.712%, 95% Wilson CI 8.398–9.036%; safe-session ALLOW recall 94.599%, CI 94.333–94.853%.
- threshold 0.80: unsafe ALLOW risk 0.286%, CI 0.227–0.360%; safe-session ALLOW recall 86.419%, CI 86.020–86.808%.
- threshold 0.85: 0 unsafe events among 24,913 ALLOW decisions, but the Wilson interval is 0.000–0.015%, so the observed zero is not interpreted as proof of zero risk.
- threshold 0.95: 0 unsafe events among only 1,600 ALLOW decisions; the upper bound widens to approximately 0.240%, illustrating why zero-event results must be reported with denominators and uncertainty.

The large point-estimate change from threshold 0.75 to 0.80 remains much larger than the finite-sample interval widths under this synthetic generator.

## Limitations

All observations and labels are synthetic. The intervals quantify sampling uncertainty conditional on the authored generator; they do not quantify generator misspecification, production prevalence, unseen attack behavior, dataset shift, telemetry measurement error, or external validity. No confidential employer data were used. No real-world effectiveness claim is made.

The GitHub connector can write source and tests but does not provide a Python execution environment. Numerical values were independently recomputed from the repository's current generator and trust-model definitions; the committed pytest tests were not executed through GitHub in this run.
