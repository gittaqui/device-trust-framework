# Research Log — 2026-09-15

## Objective
Test whether policy conclusions depend strongly on the synthetic generator's fixed scenario prevalence.

## Repository state inspected
The latest prior work was the leave-one-signal-out ablation study (`9a82d7f`). Existing code already included additive, identity-guarded, and attribute-quorum policies, so this run reused those implementations rather than introducing another policy.

## Fresh literature verification
Verified Pablo González, Alejandro Moreo, and Fabrizio Sebastiani, *Binary quantification and dataset shift: an experimental investigation*, Data Mining and Knowledge Discovery 38 (2024), 1670–1712, DOI `10.1007/s10618-024-01014-1`. The paper's controlled prevalence-shift protocols support explicitly testing performance across changed mixture prevalence while holding conditional distributions fixed. It also cautions that robustness under one type of dataset shift does not imply robustness under others.

## Work completed
- Added `src/evaluate_prevalence_shift.py`.
- Added targeted tests in `tests/test_prevalence_shift.py`.
- Evaluated five explicitly synthetic scenario mixtures, 50,000 sessions each, seed `20260915`.
- Recorded results in `results/prevalence-shift-results.md`.
- Added the verified dataset-shift paper to the bibliography and literature matrix.

## Result
Across all five authored prevalence mixtures, qualitative policy ordering remained stable: the identity guard materially reduced unsafe false ALLOW relative to additive scoring, while the 7-of-8 quorum produced no false ALLOW in these synthetic samples at the cost of more safe STEP_UP. Additive false ALLOW was strongly mixture-dependent, reaching 26.95% under the identity-heavy stress mix and falling to 8.17% under the hard-gate-heavy mix.

## Interpretation boundary
These are synthetic stress-test results. The mixtures are not empirical estimates of enterprise endpoint populations. The experiment changes scenario prevalence only and therefore does not establish robustness to within-scenario covariate shift, concept shift, new attack classes, or real telemetry.

## Validation
Numerical outputs were independently recomputed during this run from the repository's published signal ranges, model weights, hard gates, and policy definitions. The GitHub connector does not execute pytest, so no repository-wide test-suite pass is claimed here.

## Next step
Prefer the already-frozen external telemetry evaluation. If external telemetry remains unavailable, perturb within-scenario conditional signal distributions prospectively to test covariate-shift sensitivity rather than adding more prevalence mixtures.
