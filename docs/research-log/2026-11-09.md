# Research log — 2026-11-09: conditional unsafe-device bootstrap

## Existing state
Inspected main-branch `src/longitudinal_cluster_bootstrap.py`, `tests/test_longitudinal_cluster_bootstrap.py`, and `docs/research-log/2026-11-08.md`. Existing all-device bootstrap remains unchanged for sensitivity analysis.

## Contribution
Added `src/conditional_unsafe_bootstrap.py` and `tests/test_conditional_unsafe_bootstrap.py`. The primary estimator now resamples K unsafe devices (complete paired device records) with replacement, rather than all N devices and dropping undefined draws. Point estimate and bootstrap replicates use interval-weighted differences in ordinary ALLOW proportions conditional on unsafe synthetic scenario labels. With K>=2, denominator is strictly positive. A 95% interpolated percentile interval is reported. Reproducible seed, eligible cluster count, and resampling unit are exposed.

## Results and verification
A locally developed equivalent implementation passed ten unit tests and Python compilation. The GitHub-committed implementation and tests were written separately through the GitHub connector; they have **not** been run in a clean repository checkout, so do not claim repository CI success. No new device-trust effectiveness measurements were generated. Analytical sparse example: for N=100, K=2, all-device bootstrap has undefined-replicate probability 0.98^100 ≈ 13.26%, whereas unsafe-only resampling has zero undefined replicates by construction.

## Peer-reviewed source verified 2026-11-09
Field, C. A., and Welsh, A. H. (2007), “Bootstrapping clustered data,” *Journal of the Royal Statistical Society: Series B*, 69(3), 369–390, DOI 10.1111/j.1467-9868.2007.00593.x. Publisher metadata: https://academic.oup.com/jrsssb/article-abstract/69/3/369/7109361 . Supports attention to resampling units; does not prove nominal coverage of this estimator or device-trust effectiveness.

## Limitations
Conditional estimator targets unsafe-device risk, not prevalence-weighted population harm. With only K=2 eligible clusters, percentile CI coverage may be poor even though denominators are defined. Device independence fails for shared outage episodes. Synthetic scenario labels are not independently adjudicated. No confidential employer data used. Full tests, CI coverage simulation, and manuscript compilation remain outstanding.

## Next step
Run committed tests in a clean checkout, then conduct Monte Carlo coverage studies across K and heterogeneous device interval lengths, and integrate the estimator with the existing longitudinal decision engine. Keep real-world effectiveness claims out of the manuscript until independent validation.
