# Research Log — 2026-09-17

## Objective

Test a structural assumption left implicit in the synthetic generator: conditional independence of telemetry dimensions within each scenario.

## Work completed

1. Inspected the current repository state; the previous experiment tested within-scenario marginal shifts but still sampled signals independently.
2. Verified a peer-reviewed cyber-risk dependence reference before adding it: Carannante, D'Amato, Fersini, Forte, and Melisi, *Applied Stochastic Models in Business and Industry* 39(4), 549–566 (2023), DOI `10.1002/asmb.2767`.
3. Added `src/evaluate_signal_dependence.py`, which uses a one-factor Gaussian copula to induce dependence among safety-oriented factors while preserving the existing scenario-specific marginal ranges.
4. Added targeted tests in `tests/test_signal_dependence.py` for range preservation, parameter validation, determinism, and bounded output rates.
5. Ran an independent numerical reconstruction of the committed algorithm for 50,000 rows per condition, seed `20260917`, and recorded results in `results/signal-dependence-results.md`.
6. Updated `paper/references.bib` and `research/literature-matrix.csv`. The literature-matrix update also repaired the omission of the already-verified Sugiyama et al. nonstationarity reference.

## Results

Increasing the latent Gaussian dependence parameter from `rho=0.0` to `rho=0.8` increased additive false ALLOW from **12.71% to 19.96%** and guarded false ALLOW from **1.40% to 9.67%**. Safe STEP_UP changed much less (additive/guarded: 5.29% to 6.20%). The quorum comparator remained at 0% false ALLOW under these authored scenarios.

The important finding is that the identity/behavior guard's apparent robustness is materially weaker once telemetry evidence co-moves. This exposes conditional independence as a consequential synthetic-design assumption.

## Limitations

- All results are synthetic; no production, employer, Intune, Entra, or EDR telemetry was used.
- The one-factor Gaussian copula is a controlled stress mechanism, not an empirically estimated endpoint-telemetry dependence model.
- Real telemetry may have asymmetric or tail dependence that this experiment does not capture.
- The quorum result remains strongly aligned with the authored scenarios and is not evidence of production superiority.
- The GitHub connector can write source/tests but cannot execute pytest. A local clone attempt from the execution environment failed because DNS could not resolve `github.com`; therefore no repository-wide test-suite pass is claimed.

## Next step

External validation remains the highest priority. If external telemetry is still unavailable, the next synthetic robustness step should combine **heterogeneous pairwise/tail dependence with increased safe/unsafe marginal overlap**, prospectively specified before inspecting outcomes. That would challenge both the Gaussian dependence assumption and the unusually separable authored scenarios.
