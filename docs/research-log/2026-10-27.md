## Research advance

Added an operational-coverage subsection and a separate IEEE table to distinguish:
- Ordinary-ALLOW coverage = ALLOW / all observations.
- Unsafe among ALLOW = unsafe ALLOW / all ALLOW decisions (prevalence-sensitive).
- Unsafe-ALLOW rate = unsafe ALLOW / all unsafe observations.
- Safe friction = (safe STEP_UP + safe DENY) / all safe observations.
- STEP_UP is an authentication deferral; DENY is an explicit decision. They should not be conflated.

The frozen evidence comprises 50,000 synthetic observations (29,033 safe and 20,967 unsafe), 25% nominal missingness, mask seed 20260904. Policies share masks within a regime, not between regimes. Confidence-adjusted and pessimistic scoring are algebraically equivalent in the current implementation and are not counted as distinct comparators.

Under critical-signal-biased missingness, renormalization yielded 60.85% ordinary-ALLOW coverage, 14.01% unsafe among ALLOW, and 9.88% safe friction. Pessimistic scoring yielded 17.69%, 2.43%, and 70.28%, respectively. These are post-hoc descriptive synthetic results, not calibrated probabilities or production-effectiveness estimates.
